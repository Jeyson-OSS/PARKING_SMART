# 🚗 PARKING SMART
### Sistema Inteligente de Gestión de Parqueos

## Descripción del proyecto

PARKING SMART es un sistema de escritorio desarrollado en Python que permite administrar y controlar las operaciones de un parqueo.

El sistema facilita el registro de entradas y salidas de vehículos, el cálculo automático de tarifas, el control de espacios disponibles, la consulta del historial y la generación de reportes de ingresos.

## Tecnologías utilizadas

- Python
- Tkinter
- SQLite
- Matplotlib
- Pillow

## Funcionalidades principales

- Registro de vehículos.
- Control de entradas y salidas.
- Cálculo automático del costo del estacionamiento.
- Control de espacios disponibles.
- Historial de vehículos.
- Búsqueda por número de placa.
- Reportes y gráficas de ingresos.

## Capacidad del parqueo

30 vehículos.

## Ejecución del proyecto

1. Instalar Python.
2. Instalar las dependencias:

   `pip install -r requirements.txt`

3. Ejecutar el programa:
